Comments:
The class is straightforward, and the method names make it clear how coins and lives are updated. Since that is currently all it handles, I think those values could just live in GameSession instead of having another object to pass through the collision setup.

We could add these methods to the existing IGameActions interface:

void AddCoin();
void AddLife();

GameSession would implement them, and MarioItemCollisionHandler would call them through IGameActions. This would let collision code update coins and lives without needing access to everything else in GameSession.

Hypothetical change:
Give Mario an extra life after collecting 100 coins. The current code could handle that in GameProgress.AddCoin. With the proposed change, the same rule would go in GameSession.AddCoin, and the collision handler would still just call AddCoin.
